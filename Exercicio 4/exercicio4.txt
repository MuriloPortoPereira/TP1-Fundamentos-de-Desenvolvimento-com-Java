--------- Observações sobre IntelliJ IDEA --------- 


Observações sobre a execução do arquivo ao longo do primeiro contato com o IntelliJ IDEA:

Para executar o código Java na IDE, é necessário criar um arquivo com a extensão `.java`, preferencialmente dentro da pasta `src` (source / fonte / origem), onde ficam os arquivos de código-fonte do projeto. O nome do arquivo deve ser igual ao nome da classe pública declarada nele. Além disso, a classe deve conter o método `public static void main(String[] args)`, que é o ponto de entrada para a execução do programa.

--------- Executar sem Metodo ---------

Ao tentar executar o código sem o método main, ocorreu um erro, pois as instruções estavam soltas, fora de uma classe e de um método.

Entendi que, para executar o programa da maneira tradicional, precisamos colocar as instruções dentro do método main, que fica dentro de uma classe.

Porém, para apenas compilar uma classe Java, não é obrigatório ter o método main.

--------- Conteúdo Sobre: Acesso --------- 

O Java podem ter 4 níveis de acesso:

// Public: Acesso Total, qualquer classe de qualquer pasta do projeto pode ver e usar.

// Protected: Acesso Restrito a Herança. Apenas Classes da mesma pasta ou filhas podem acessar.

// Sem palavra: So as classes que estão na mesma pasta podem interagir com ela.

// Private: Acesso exclusivo, apenas o código que esta dentro das { } da própria chave pode ver.

// void: Indica que o método não retorna nenhum valor.

--------- Conteúdo Sobre: Estrutura de pastas de um projeto Java --------- 

Ao criar um projeto Java no IntelliJ IDEA, percebi que é importante entender como funciona a organização das pastas e dos arquivos.

A pasta `src`, que vem da palavra *source* (fonte), é onde normalmente ficam os códigos-fonte do projeto. Dentro dela, podemos criar uma **Java Class**, que gera um arquivo com a extensão `.java`.

Por exemplo, ao criar uma classe chamada `Exercicio4`, a IDE gera o arquivo `Exercicio4.java`. O nome do arquivo precisa ser igual ao nome da classe pública declarada dentro dele.

Para executar um programa Java tradicional, utilizamos o método `public static void main(String[] args)`, que indica por onde a execução começa.

Quando compilamos o arquivo `.java`, o compilador `javac` transforma o código-fonte em um arquivo `.class`, que contém o *bytecode*. Esse bytecode é executado pela JVM (Java Virtual Machine).

Assim, entendi que a organização das pastas ajuda a manter o projeto estruturado, enquanto os arquivos `.java` armazenam o código que escrevemos e os arquivos `.class` contêm o resultado da compilação.


MeuProjeto/
├── .idea/                 # Configurações do IntelliJ
├── src/                   # Código-fonte
│   ├── InfoAmbiente.java  # Classe Java
│   └── Exercicio4.java    # Outra classe Java
├── out/                   # Arquivos compilados pela IDE
│   └── production/
│       └── MeuProjeto/
│           └── Exercicio4.class
└── MeuProjeto.iml         # Configuração do módulo, se existir

--------- Conteúdo Sobre: Padrões de Nomenclatura em Java ---------

Em Java, existem 3 padrões principais para nomear classes,
variáveis, métodos e constantes.

Esses padrões ajudam a organizar o código e facilitam a leitura.


1. PascalCase - Classes

A primeira letra de cada palavra começa com maiúscula. As palavras ficam juntas, sem espaços.

- Exemplos:
public class Exercicio4 { }
public class SegurancaSistema { }
class CalculadoraInterna { }

Correto: SegurancaSistema

Fora do padrão: segurancaSistema


2. camelCase - Variáveis e Métodos

- A primeira palavra começa com letra minúscula.
- As próximas palavras começam com letra maiúscula.
- Não utilizamos espaços entre as palavras.

- Exemplos:
int idadeMinima = 18;
boolean podeEntrar = true;
double valorTotal = 150.50;

- Exemplos de nomes de métodos:
calcularIdade()
verificarEntrada()

Correto: idadeMinima

Fora do padrão: IdadeMinima


3. UPPER_SNAKE_CASE - Constantes

- Todas as letras são maiúsculas.
- As palavras são separadas por underline (_).
- Normalmente utilizamos static final para constantes de classe.

- Exemplos:
static final int IDADE_MINIMA = 18;
static final double TAXA_CONVERSAO = 1.60934;

Correto: IDADE_MINIMA

Fora do padrão: idadeMinima


--------- Resumo ---------

PascalCase      = Classes

camelCase       = Variáveis e métodos

UPPER_SNAKE_CASE = Constantes


--------- Observações ---------

Java diferencia letras maiúsculas de minúsculas.

Isso é chamado de Case Sensitive.

idadeMinima e IdadeMinima são nomes diferentes.

Esses padrões são convenções de programação. Não são regras obrigatórias da linguagem.

Porém, seguir esses padrões facilita a leitura, a organização e a manutenção do código.

IMPORTANTE:

O nome de um arquivo .java que contém uma classe pública deve corresponder exatamente ao nome dessa classe.

Exemplo:

Classe: public class Exercicio4

Arquivo: Exercicio4.java
